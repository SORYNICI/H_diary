# H_diary · 세트일지 — Android 프로토타입

부위 → 운동 → 무게·횟수 선택 → 세트 추가로 운동을 기록하는 네이티브 Android 앱입니다.

## 구현한 기능

- 가슴, 어깨, 등, 이두, 삼두, 하체, 복근의 운동 목록
- 무게 프리셋, 2.5kg 증감, 직접 입력 / 횟수 프리셋, 증감, 직접 입력
- 같은 무게·횟수를 유지한 연속 세트 기록
- 세트 수정, 복사, 삭제
- 날짜 이동, 날짜 선택, 지난 일지 목록
- 같은 부위·운동의 세트를 한 카드로 묶고 PNG에도 같은 방식으로 표시
- 부위 버튼: 가슴·어깨·등 / 이두·삼두·하체·복근
- 무게 프리셋: 0·10·20·40·60·80kg / 횟수 프리셋: 5·8·10·12·15·20회
- 프리셋은 화면 폭과 글자 크기에 따라 한 줄 또는 3개씩 두 줄로 표시
- 앱 재시작 후에도 유지되는 휴대폰 내부 저장
- 일지 PNG 저장 및 Android 공유 메뉴
- Android 8~9에서는 파일 저장 위치 선택, Android 10 이상에서는 갤러리 저장

## 실행

### Android Studio 설치 없이: GitHub Actions

1. GitHub 저장소를 만들고 이 프로젝트를 업로드합니다. `.github/workflows/build-apk.yml`도 포함해야 합니다.
2. 저장소의 **Actions → Build Android APK → Run workflow**를 실행합니다. 기본 브랜치가 main/master라면 업로드 시에도 자동 실행됩니다.
3. 실행이 성공하면 하단 **Artifacts → set-diary-debug-apk**를 다운로드하고 ZIP을 풉니다.
4. `app-debug.apk`를 Android 휴대폰에 보내 설치합니다. 휴대폰이 요청하면 APK를 여는 앱에 대해 ‘이 출처 허용’을 설정합니다.

GitHub 계정에 로그인해야 빌드 결과를 다운로드할 수 있습니다. 이 APK는 프로토타입 확인용 debug 버전입니다. 이 자동 빌드 설정은 추가했지만 아직 GitHub에서 실행하지 않았습니다.

### Android Studio로 실행

필요 환경: Android Studio, JDK 17, Android SDK 35, Gradle 8.9.

1. Android Studio에서 이 폴더를 프로젝트로 엽니다.
2. Gradle 설정에서 JDK 17과 Gradle 8.9를 지정합니다. 이 프로젝트에는 Gradle wrapper 바이너리가 포함되어 있지 않습니다. Gradle 8.9가 설치되어 있다면 프로젝트 루트에서 `gradle wrapper --gradle-version 8.9`로 생성할 수 있습니다.
3. Android SDK 35를 설치하고 프로젝트 동기화를 실행합니다.
4. Android 8.0 이상 에뮬레이터 또는 USB 디버깅을 켠 휴대폰을 선택한 후 Run을 누릅니다.

설치용 APK: Android Studio의 Build 메뉴에서 APK를 생성하거나 `gradle :app:assembleDebug`를 실행합니다. 결과는 `app/build/outputs/apk/debug/app-debug.apk`입니다.

## 직접 확인할 시나리오

1. 가슴 → 벤치 프레스 → 40kg → 10회 → 세트 기록을 두 번 누릅니다. 2개 세트가 표시되는지 확인합니다.
2. 등 → 랫 풀다운 → 20kg → 12회로 세트를 추가합니다.
3. 세트의 수정 메뉴에서 수정, 복사, 삭제를 확인합니다.
4. 앱을 종료하고 다시 열어 기록이 남아 있는지 확인합니다.
5. 다른 날짜에 기록을 추가하고 지난 일지에서 두 날짜를 확인합니다.
6. 이미지 저장 후 갤러리 또는 지정한 파일 위치에서 PNG를 열고, 이미지 공유로 다른 앱에 전달합니다.
7. 화면 회전 후 날짜, 선택한 운동, 입력 값이 유지되는지 확인합니다.

## 현재 범위와 검증 상태

로그인, 서버 동기화, 운동 목록 추가는 포함하지 않은 첫 프로토타입입니다. 기록은 현재 휴대폰에만 보관되며 앱 삭제 시 함께 삭제됩니다. 무게 0kg는 맨몸 운동을 뜻하며 총 볼륨 계산에는 0으로 반영됩니다. 각 덤벨의 무게 또는 양쪽 합산 무게 중 자신의 기준으로 일관되게 입력하세요.

APK는 GitHub Actions에서 빌드합니다. 실제 휴대폰 및 에뮬레이터 동작 검증은 별도로 필요합니다.
